Раздел 02

Материалы по твёрдости

От мягкой сосны до твёрдого дуба. Откройте материал: графики цен, лучший вариант покупки, описание для дизайнеров и режимы обработки.

Шкала плотности древесины
кг/м³ · влажность 12 %

Плотность — масса древесины в одном кубометре при влажности 12 %: чем она выше, тем тяжелее и, как правило, твёрже порода. Метки стоят строго по значению. Данные: The Wood Database (сосна обыкновенная, берёза повислая, дуб черешчатый, ясень обыкновенный, бук лесной). Для фанеры взято значение цельной берёзы: реальная плотность зависит от шпона и клея.

BL-UsbMach V2.1 для Mach3

Плагин связи Mach3 с USB-платой управления станком (STEP2MACH). Версия для 32-битного Mach3.

Скачать .zip · 107 КБ ↓
Файлbl-UsbMach.dll
Разрядностьx86 (32 бит)
СистемаWindows, Mach3
  • 1Закройте Mach3 и распакуйте архив.
  • 2Скопируйте bl-UsbMach.dll в папку PlugIns каталога Mach3 (обычно C:\Mach3\PlugIns).
  • 3Запустите Mach3 и включите плагин в Config → Config Plugins.

В архиве есть служебный dllme.txt: файл скачан с dllme.com, перед установкой проверьте его антивирусом.
